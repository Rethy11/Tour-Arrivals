Privacy Policy

Last updated August 7, 2026

Short version

This tool runs entirely in the browser. It has no server or backend of its own, so it never uploads, transmits, or sees the schedule files you load into it.

The schedule file you load

When you upload or auto-load a saved schedule export, it's read and parsed locally on your device using JavaScript. The arrival times, guest counts, and crew names it extracts are kept only in the browser tab's memory — closing or reloading the page clears them.

Auto-load folder access

If you grant this tool access to a local folder so it can automatically load today's schedule, that folder permission is remembered using your browser's local storage (IndexedDB), on your device only. It isn't sent anywhere, and you can revoke it at any time by clearing your browser's site data or choosing a different folder.

Data collection

This tool doesn't operate a backend, database, or analytics service. It doesn't collect names, usage data, or any information about who's using it, beyond what briefly exists in your browser tab while it's open.

Cookies

This tool doesn't set cookies.

Hosting

This tool is hosted on GitHub Pages. GitHub may log basic server access information (like IP address and request time) as part of operating its hosting infrastructure; that's governed by GitHub's own privacy statement, not by me.

Intended use

This tool was built for one specific business's internal, day-to-day use, and the schedule data it displays (guest counts, crew names, arrival times) is that business's own internal information. It isn't intended to be used, or to display data, outside that context.

Changes

If anything about how this tool handles data ever changes, this page will be updated and the date above will change.

Contact

Questions can be raised as an issue on GitHub.
